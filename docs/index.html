Cómo avanza cada docente

  1. Usted compara los datos, carga el acta y envía al revisor.
  2. El revisor aprueba o le devuelve el expediente para corregir.
  3. El revisor lo radica ante el MEN, en la plataforma del Ministerio, fuera de esta aplicación.
